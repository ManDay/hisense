# Installation

Download a compatible https://github.com/TrebleDroid/treble_experimentations/wiki/Generic-System-Image-%28GSI%29-list[Generic System Image]. To check compatibility, use https://f-droid.org/packages/vegabobo.dsusideloader[DSU Sideloader] (or the respective option in "`Developer Options`") to try out whether arbitrary `system.img` files boot with the device.

Follow along the instructions of `install.sh` to create a flashable *Super*-Image.

Mind the following caveats and limitations

* The Treble settings app will attempt to reset "Disable HW Overlays" unless you activate the option through "`Developer Options`" or the Treble app itself
